How is compatibility verified?

A download is marked Verified working only after it is launched in the specified Minecraft version with the matching loader and its successful test is documented. Currently no existing JAR has such a recorded test, so all downloads are marked Not verified. Build success and ZIP integrity checks do not count as gameplay verification.

Where do these files come from?

Existing archive: All listed downloads are files already committed to this repository. Their original download locations have not been independently verified. The source field is not an endorsement or proof of authenticity.
